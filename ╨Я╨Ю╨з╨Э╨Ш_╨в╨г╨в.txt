🌃 НЕОН — ПОВНІСТЮ БЕЗКОШТОВНИЙ ВАРІАНТ

1. Відкрий README.md — там інструкція українською.
2. Розпакуй цей архів.
3. Завантаж ВМІСТ папки в порожній GitHub-репозиторій (не завантажуй ZIP як один файл).
4. Створи безкоштовну БД Cloudflare D1 та впиши її ID у wrangler.toml через GitHub.
5. Під'єднай GitHub до Cloudflare Workers Free.
6. У Cloudflare Secrets вкажи BOT_TOKEN, WEBHOOK_SECRET, SETUP_KEY.
7. Відкрий /setup?key=... для автоматичного підключення до Telegram.
8. Додай бота в Telegram-групу та запусти /newgame.

Платна підписка, VPS, локальний Python і командний рядок не потрібні.
