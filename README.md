# НЕОН: ВІЙНА КОРПОРАЦІЙ — БЕЗКОШТОВНО НА CLOUDFLARE

**Кіберпанк-мафія у Telegram, 6–16 гравців, 26 ролей, Арасака, кіберпсихи, імпланти.**

Це **окрема Cloudflare-версія** попереднього Python-проєкту. Вона написана на JavaScript, щоб працювати через Telegram Webhook і Cloudflare Workers, а не запускати `run_windows.bat`. Поточна версія не імпортує стару SQLite-базу `neon.db`; нові матчі зберігаються в Cloudflare D1.

## Витрати

- GitHub Free: 0 грн для репозиторію.
- Cloudflare Workers Free: 100 000 запитів на день, обмеження CPU часу 10 мс на запит.
- Cloudflare D1 Free: 5 млн прочитаних і 100 тис. записаних рядків за день, до 5 ГБ зберігання.
- `workers.dev` HTTPS-адреса: безкоштовно; власний домен не потрібний.
- Платіжну картку для Workers Free вказувати не потрібно. Понад ліміти послуга може перестати обробляти запити до відновлення квоти. Безкоштовний тариф і умови можуть змінюватися за рішенням провайдера.

Офіційно: https://developers.cloudflare.com/workers/platform/limits/ та https://developers.cloudflare.com/d1/platform/pricing/.

## Покроково: лише браузер, без Python, Git і CMD

### 1. Підготуй GitHub

1. Відкрий https://github.com/new і створи порожній репозиторій `neon-night-city-mafia` (Private або Public; краще Private).
2. Відкрий репозиторій → **Add file** → **Upload files**.
3. У ZIP-архіві є папка `NEON_CLOUDFLARE_FREE`. **Розпакуй її**, відкрий всередині та перетягни **її ВМІСТ** у вікно GitHub, а не сам ZIP чи ще один вкладений каталог.
4. Підтвердь **Commit changes**. У корені GitHub-репозиторію повинні бути `wrangler.toml`, `package.json`, `README.md`, а також папка `src` із трьома файлами.

### 2. Створи БД D1 у Cloudflare

1. Відкрий https://dash.cloudflare.com/ та зареєструй безкоштовний акаунт.
2. У Cloudflare знайди **Storage & databases → D1 SQL database** (назва меню може дещо відрізнятися).
3. Натисни **Create database**. Назва: `neon-night-city`. Натисни Create.
4. Відкрий створену базу та скопіюй її **Database ID** (UUID).
5. Повернися на GitHub → файл `wrangler.toml` → значок олівця **Edit**.
6. Заміни `REPLACE_WITH_YOUR_D1_DATABASE_ID` у рядку `database_id` на скопійований UUID.
7. Збережи зміни через **Commit changes**. Не змінюй `binding = "DB"`.

### 3. Розгорни Worker напряму з GitHub

1. У Cloudflare відкрий **Workers & Pages → Create application**.
2. Обери **GitHub** і підключи свій обліковий запис GitHub (дозвіл на репозиторій надаєш сам).
3. Обери репозиторій `neon-night-city-mafia`.
4. Підтверди налаштування. Назва Worker має дорівнювати `neon-night-city-mafia` (як у `wrangler.toml`), root directory — `/`, команда deploy — `npx wrangler deploy` (якщо просять), build command — порожня або `npm install` (якщо обов'язкова).
5. Натисни **Save and Deploy**. Дочекайся успішного результату.
6. Cloudflare надасть адресу `https://neon-night-city-mafia.<твій-subdomain>.workers.dev`.
7. Відкрий `<адреса>/health`. Повинно показати `NEON CITY ONLINE`.

### 4. Внеси 3 секрети на Cloudflare (НЕ на GitHub)

Worker → **Settings → Variables and Secrets → Add**. Додай три значення з типом **Secret**:

- `BOT_TOKEN`: справжній токен твого Telegram-бота від https://t.me/BotFather.
- `WEBHOOK_SECRET`: довгий **випадковий** набір латинських букв, цифр, `_`, `-`, без пробілів. Це код перевірки повідомлень від Telegram, 16–64 символи.
- `SETUP_KEY`: ще один **інший** довгий випадковий секрет, також без пробілів.

Після цього натисни Deploy/Save. Токен не клади до репозиторію, не пиши в коді й не публікуй у чаті.

### 5. Один раз прив'яжи Telegram webhook

У браузері відкрий:

`https://neon-night-city-mafia.<твій-subdomain>.workers.dev/setup?key=<ТВІЙ_SETUP_KEY>`

Встав власну адресу й власний `SETUP_KEY` **тільки у своєму браузері**. Якщо успіх, побачиш повідомлення **«Готово! Telegram @... підключено до Cloudflare»**. Сторінка сама створює таблиці в D1, реєструє команди та налаштовує Telegram webhook. Секрет у цьому URL не є BOT_TOKEN, але його також не можна розголошувати; за потреби після setup можна змінити SETUP_KEY.

### 6. Запусти матч

1. Додай бота до Telegram-групи (через @BotFather може знадобитися `/setjoingroups`).
2. Відправ `/newgame` у групу.
3. Кожен гравець натискає **«Приєднатися»** та запускає особистий чат із ботом.
4. Після 6–16 учасників організатор відправляє `/begin`.
5. Далі ролі та дії надходять особисто, через `/panel` можна вибирати цілі й купувати імпланти.

**Час фаз:** ніч — 100 с, день — 150 с, суд — 75 с за замовчуванням. Автоматичне перемикання реалізоване Cloudflare Cron Trigger раз на хвилину, тому завершення фаз може запізнитися приблизно до хвилини. Організатор може перемикати вручну командою `/next`.

## Команди

У групі: `/newgame`, `/join`, `/begin`, `/status`, `/next`, `/history`, `/roles`, `/rules`, `/top`, `/cancel`.
В особистих повідомленнях: `/start`, `/panel`, `/role`, `/rules`, `/history`.

## Що в архіві

- `src/data.js` — усі 26 ролей і 6 імплантів;
- `src/engine.js` — правила, баланс, нічний розрахунок, суд, виграші;
- `src/index.js` — Telegram Bot API, кнопки, D1, webhook і cron;
- `wrangler.toml` — конфігурація Worker з cron і D1;
- `package.json` — метадані проєкту; локально нічого встановлювати не потрібно;
- `tests/` — автоматичні тести (локально `node --test` за бажанням).

## Межі перевірки

- Автоматичні тести та симуляції рушія запускалися локально з імітацією Telegram та D1.
- Реальне розгортання в твоєму Cloudflare та надсилання повідомлень Telegram не перевірене, бо для цього потрібні твої акаунти й секрети.
- Поки що немає перенесення старих баз SQLite, для кожної групи зберігається один матч; у разі одночасних швидких натискань можлива відповідь «Повтори дію» через захист від конфліктів запису.
